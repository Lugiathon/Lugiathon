## What I'm Building

- [Wenxuecity Ad Hider](https://github.com/Lugiathon/wenxuecity-ad-hider) makes reading Wenxuecity calmer with a browser extension and userscript.

I share these projects so others can see the ideas, the problem-solving steps, and the parts that still need improvement.
